# 교회 홈페이지 네이버 검색 노출

## 결론 (2026-11-25 확인)

새 교회 홈페이지(`*.stayon-platform.com`)가 네이버 검색에 나오게 한 방법:
**루트 도메인 `stayon-platform.com`을 네이버 서치어드바이저에 등록하고, 모든 교회 주소가 담긴 사이트맵을 제출함**.

- 2026-11-24 00:35 사이트맵 제출 → 하루쯤 뒤 대구나눔의교회가 검색에 나옴
- 검색 결과에서 교회들이 "stayon-platform.com" 아래에 묶여 나옴

## 그 전에 안 됐던 상태

- 교회별 서치어드바이저 등록, 소유확인, 사이트맵, RSS, 수집 요청을 다 했는데도
  "수집 완료 / 색인 안 됨"이 일주일 동안 이어짐
- **계정 문제가 아님**: 네이버는 어느 계정으로 만들었는지 볼 수 없음
- **글자 수 문제도 아님**: 글자가 더 많은 베다니 홈페이지도 안 나왔음

## 구성

| 주소 | 하는 일 |
|---|---|
| `https://stayon-platform.com/sitemap.xml` | 모든 교회 주소 사이트맵 (아래 주소 내용을 그대로 내보냄) |
| `https://bulletin.stayon-platform.com/church-sitemap.xml` | 발행된 교회 사이트 전체 목록 (`churchSitemap` 함수, 발행 시 자동 반영) |
| `https://stayon-platform.com/naver….html` | 네이버 소유확인 파일 자동 응답 |
| `https://stayon-platform.com/` 그 외 | place.stayon-platform.com 으로 301 이동 (수련회 서비스 그대로) |

- 처리하는 곳: Cloudflare Worker **`stayon-root-sitemap`**
  (경로: `stayon-platform.com/sitemap.xml`, `stayon-platform.com/naver*`)
- 교회 사이트용 Worker `flat-shape-14`는 건드리지 않음

## 같은 날 함께 고친 것 (효과는 확인 안 됨)

`functions/src/index.ts`의 교회 홈페이지 부분(`siteOG`):
- bulletin 사이트용 네이버 소유확인 코드 `fad7558…`가 모든 교회 홈페이지에 붙어 나가던 것을 뺌 (`stripBulletinNaverCode`)
- 사이트 이름(`og:site_name`)이 모든 교회에서 "스테이온(STAYON)"이던 것을 각 교회 이름으로 바꿈 (`withChurchSiteName`)

## 앞으로

- 새 교회가 검색에 안 나오면: 먼저 그 교회가 루트 사이트맵에 들어 있는지(사이트가 발행 상태인지) 확인
- 교회가 100곳쯤 되면 사이트맵을 여러 개로 나누기 (한 사이트맵에 주소 5만 개 제한)
